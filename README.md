# Album Cover Studio — PDA-226

> SE226 Course Project · İzmir University of Economics

Album Cover Studio is a Python desktop application that turns a journal entry or mood description into a fully generated fictional album. Type how you're feeling, pick a genre and era, and the app produces an album name, artist, year, record label, AI-generated cover artwork, and a real tracklist pulled from Last.fm — all presented in a Spotify-style dark UI.

---

## Features

- **Free-form journal / mood input** — describe your day, a feeling, or any text prompt
- **Genre selection** — Pop, Rock, Hip-Hop/Rap, Electronic, Indie, R&B/Soul, Jazz, Metal, Türk Pop, Klasik
- **Era selection** — 1970s through 2020s
- **Track count** — 6 to 14 tracks
- **AI-generated album metadata** — fictional album name, artist, year, record label, and mood summary via Google Gemini
- **Real tracklist** — actual songs fetched from Last.fm matching the genre and era
- **AI cover art** — unique cover image generated by Pollinations.ai
- **Spotify-style dark UI** — emerald accent theme built with Tkinter, rounded corners throughout
- **Clickable Listen buttons** — open the Last.fm page for each track in your browser
- **Export** — save the full album as a JSON file and the cover art as a PNG

---

## Tech Stack

| Layer | Technology |
|---|---|
| GUI | Python · Tkinter |
| AI metadata | Google Gemini API |
| Song data | Last.fm API |
| Cover art | Pollinations.ai |
| Image handling | Pillow (PIL) |
| Background tasks | Python `threading` |

## Project Structure

```
PDA226/
├── main.py             # App entry point — initialises Tk root and launches AlbumApp
├── gui.py              # Tkinter GUI — AlbumApp class, all widgets and layout
├── styles.py           # Color and font constants for the dark emerald theme
├── gemini_service.py   # Google Gemini integration — generates fictional album metadata
├── lastfm_service.py   # Last.fm API integration — fetches real tracks by genre/era
├── image_service.py    # AI image generation via Pollinations.ai
├── export_service.py   # Exports album data as JSON and cover art as PNG
├── thread_manager.py   # Runs generation pipeline in background threads
└── config.py           # API keys — NOT committed to Git (see setup below)
```

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/ecekabasakal/PDA226.git
cd PDA226
```

### 2. Install dependencies

```bash
pip install google-generativeai requests pillow
```

### 3. Create `config.py`

Create a file named `config.py` in the project root with your API keys:

```python
GEMINI_API_KEY  = "your_gemini_api_key_here"
LASTFM_API_KEY  = "your_lastfm_api_key_here"
```

> `config.py` is listed in `.gitignore` and will never be committed.

### 4. Run the app

```bash
python3 main.py
```

## Getting API Keys

### Google Gemini (free)

1. Go to [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. Sign in with your Google account
3. Click **Create API key** and copy it into `config.py`

### Last.fm (free)

1. Go to [last.fm/api/account/create](https://www.last.fm/api/account/create)
2. Fill in the form (application name can be anything, e.g. `AlbumCoverStudio`)
3. Copy the **API key** into `config.py`

## Usage

1. Type a journal entry or mood description in the text area
2. Select a **Genre** and **Era** from the dropdowns
3. Choose how many tracks you want with the **Track Count** spinner
4. Click **Generate Album**
5. Wait a few seconds while the app fetches data and generates art
6. Browse the tracklist — click **Listen** on any track to open it on Last.fm
7. Use the export option to save the album as JSON + PNG

---

## Important Note

The **album name, artist name, year, and record label** are entirely AI-generated fictional content created by Google Gemini — they do not represent real artists or releases. Only the **tracklist** contains real songs sourced from Last.fm.
